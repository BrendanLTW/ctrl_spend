# Design canvas source (15 Nov 2026)

The HTML source of each artboard on the "CtrlSpend UI" design canvas (https://claude.ai/artifact/QgA5yD5Z4sBGinQBdfy9m4), copied on 15 Nov 2026. Each `<File>.dc.html` is one screen at 390 × 844 (taller for S21 and S22); its dark version is the same file with the `dark` class, whose rules are in the same file's `<style>`.

These files are reference only: the app doesn't load them. Screen tasks check sizes, colours and copy against them. The PNGs one folder up are the earlier exports, kept for the screens these don't replace.
